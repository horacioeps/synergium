# Comunidad WhatsApp — funcionalidad

Análisis y acciones sobre las comunidades de investigadores de Horacio Pérez Sánchez (WhatsApp ES + EN, podcast *Investigando la investigación* / *Researching the Research*).

La vault es **solo lectura**. Todo lo generado vive aquí.

## Casos

| Caso | Qué es |
|------|--------|
| `casos/engagement-julio-2026/` | Engagement del chat ES (dic-2024 → jul-2026). Núcleo 5–6 personas; encuesta «buscar colaboradores» = mayor participación silenciosa. |
| `casos/formulario-agosto-2026/` | **Directorio único ES+EN** para emparejar miembros. Formularios listos para Google Forms, mensajes WhatsApp, playbook de matching, privacidad. Preparatorio de Synergium **sin venderlo**. |
| `formulario/nexus-input/` | Schema + i18n del form vivo `forms.synergium.net/nexus-input`. |

Form vivo: https://forms.synergium.net/nexus-input (deploy en `producto/forms/`).

## Cómo usar el formulario

1. Leer `casos/formulario-agosto-2026/00-resumen.md`.
2. Crear los dos Google Forms con `brief-google-forms.md` + `formulario-es.md` / `formulario-en.md` (o migrar a Synergium Forms cuando el MVP esté listo).
3. Pegar los mensajes de `mensaje-whatsapp-es.md` y `mensaje-whatsapp-en.md` (no soltar el link a pelo).
4. Cuando haya respuestas: `playbook-matching.md`.
5. Enlaces publicados (formularios vivos): `casos/formulario-agosto-2026/enlaces-vivos.md`.
