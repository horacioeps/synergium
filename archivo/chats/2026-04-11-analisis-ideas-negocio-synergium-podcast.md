# Sesión 2026-04-11 — Análisis ideas de negocio Synergium + campañas podcast de pago

## Qué se hizo

### 1. Análisis crítico de ideas de negocio (Synergium y derivadas)
- Se leyó la nota principal "Ideas de negocio para ayudar investigadores - Synergium - y otras" junto con todos sus backlinks y outlinks (conversaciones con Fabián y Alexander, nota 286, Manolo Castellano, Niels Tudor-Vinther, nota "partir de fortalezas").
- Se identificaron **13 ideas de negocio** dispersas en las notas.
- Se redactó un análisis con: inventario completo, crítica feroz de cada idea, y doble priorización (factibilidad + probabilidad de éxito).
- Veredicto: demasiada dispersión, 0 ingresos. Las más viables son docencia remota (corto plazo), alianza con consultoras europeas (medio plazo), y coordinación de proyectos (largo plazo).

### 2. Plantillas de email para Synergium (broker de colaboraciones)
- Se crearon 2 variantes de email para ofrecer el servicio de broker a investigadores LATAM (única variable: título del paper).
- Se adaptó el lenguaje a LATAM (sin ANECA/sexenios, usando "sistemas nacionales de ciencia", "categorización de grupos", etc.).

### 3. Plantillas de email para podcast de pago (investigadores)
- Se crearon 4 variantes (ABCD testing) para vender episodios de podcast como servicio de pago a investigadores.
- Variante B (impacto evaluativo) generó la primera respuesta real: Antia Ivett Álvarez Bernabé.
- Se analizó el buyer persona (investigadora junior, 1 paper, necesita maximizar impacto para evaluaciones).
- Se crearon 3 opciones de respuesta y se entregó texto plano listo para enviar.

### 4. Campaña de podcast de pago para EMPRESAS biotech/deeptech LATAM

## Decisiones tomadas
- El buyer persona para podcast de pago a investigadores es: junior con pocos outputs que necesita maximizar impacto evaluativo.
- Para empresas, el pitch es diferente: visibilidad ante inversores/partners/clientes, no evidencia de divulgación.
- No mencionar precio en primer contacto (ni email ni LinkedIn): el objetivo es que respondan, luego negociar.
- URLs de YouTube son mejores que Spotify para mensajes de LinkedIn (más visual, más confianza).
