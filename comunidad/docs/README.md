# Comunidad WhatsApp — funcionalidad

Análisis y acciones sobre las comunidades de investigadores de Horacio Pérez Sánchez (WhatsApp ES + EN, podcast *Investigando la investigación* / *Researching the Research*).

La vault es **solo lectura**. Todo lo generado vive aquí.

## Casos

| Caso | Qué es |
|------|--------|
| `casos/analisis-engagement-2026-07/` | Engagement del chat ES (dic-2024 → jul-2026). Núcleo 5–6 personas; encuesta «buscar colaboradores» = mayor participación silenciosa. |
| `casos/2026-08-14-formulario-matching/` | **Directorio único ES+EN** para emparejar miembros. Formularios listos para Google Forms, mensajes WhatsApp, playbook de matching, privacidad. Preparatorio de Synergium **sin venderlo**. |

Evolución hospedada (URL `forms.synergium.net/…`, BD propia, email al enviar): **`generado/synergium-forms/`** (arquitectura + schema del mismo Community directory).

## Cómo usar el formulario

1. Leer `casos/2026-08-14-formulario-matching/00-resumen.md`.
2. Crear los dos Google Forms con `brief-google-forms.md` + `formulario-es.md` / `formulario-en.md` (o migrar a Synergium Forms cuando el MVP esté listo).
3. Pegar los mensajes de `mensaje-whatsapp-es.md` y `mensaje-whatsapp-en.md` (no soltar el link a pelo).
4. Cuando haya respuestas: `playbook-matching.md`.
