## Reglas operativas (origen / canal)

### Teléfono en el formulario ≈ viene de WhatsApp

**Heurística (casi siempre, no 100% estricta):** si la respuesta incluye **WhatsApp con código de país**, el investigador llegó por la **campaña del formulario en la comunidad WhatsApp** (ES o EN). El campo P3 existe precisamente porque ese es el canal de la comunidad; quien rellena desde otro sitio suele dejar el teléfono vacío o poner uno poco fiable.

Excepciones posibles (raras): alguien externo al grupo que conoce el link y pone su móvil igualmente.

### Embudo típico podcast → cliente

```
Email campaña (p. ej. solicitud PDF / podcast)
    → entra o refuerza contacto en comunidad WhatsApp
        → mensaje + link form Community directory
            → respuesta con email + teléfono
```

Documentar en cada expediente: email previo (si hay), comunidad ES/EN, formulario, intro.
